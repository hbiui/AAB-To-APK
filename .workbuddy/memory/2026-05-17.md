## AAB To APK 项目免费部署方案

### 完成内容
- 分析了项目结构：前端 React/Vite/TS + 后端 Express/TS，核心依赖 Java 17 + bundletool.jar
- 原部署在 Replit（免费期一个月），目标迁移到永久免费平台

3. `backend/package.json` — 去掉所有 `workspace:*` 和 `catalog:` 引用，改为独立依赖
4. `frontend/vite.config.ts` — 移除 Replit 插件（runtimeErrorOverlay/cartographer/devBanner），去掉强制 PORT/BASE_PATH 环境变量依赖
5. `frontend/package.json` — 移除 `@replit/*` 插件，`catalog:` 换实际版本号

### 部署架构
- **后端**：Render 免费层（Docker，含 Java 17 + bundletool）→ `https://xxx.onrender.com`
- **前端**：Vercel 免费层（静态 Vite build）→ `https://xxx.vercel.app`
- 前端 `VITE_API_URL` 指向 Render 后端 URL
- Render 免费版有冷启动（15min 无请求休眠），可用 UptimeRobot ping /api/healthz 保活
